
# Greek (etymology) :
*on* = “being”
*logos* = “science” (in this context).

# Definition :
l’étude de ce qui existe (en d’autres termes, c’est l’*étude de l’être*).
- l’étude du “*mobilier du monde*”
# But :
Ce n’est pas de dresser un inventaire exhaustif de tout ce qui existe, mais **d’identifier les grandes catégories de ce qui existe**.
